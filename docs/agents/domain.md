# Domain Docs

This repo uses a single-context domain documentation layout.

Before exploring or changing domain-heavy code, read these if they exist:

- `CONTEXT.md` at the repo root
- `docs/adr/` ADRs relevant to the area being changed

If these files do not exist, proceed silently. Do not create them just because they are absent. Domain-modeling skills can create them later when terms or decisions are actually resolved.

Use the glossary vocabulary from `CONTEXT.md` when naming domain concepts. If a proposed change contradicts an ADR, surface the conflict explicitly.
