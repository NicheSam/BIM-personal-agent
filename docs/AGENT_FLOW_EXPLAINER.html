BIM Personal Agent
給 BIM 工程人員的運作說明

你說要做什麼，Agent 幫你在 Revit 完成

你不需要知道程式怎麼寫。Agent 會先看目前模型、找合適方法，再交給 Revit 執行；完成後告訴你改了什麼。

中間其實只經過五件事

把 Agent 想成一位會先看現場、選工具、再施工並回報的 BIM 助理。

1

你說需求

例如：「把選取的風管備註改成待檢查。」

2

Agent 看模型

確認目前專案、視圖、選取物件和可用資料。

3

選擇做法

有現成工具就直接用；沒有才建立新的做法。

4

Revit 執行

在模型內完成查詢、建立或修改，並保留 Undo。

5

回報結果

顯示成功與否、改了哪些物件、花了多久。

Agent 有三種工作方式

你不需要指定要用哪一種。Agent 會先找最直接的方法；只有現有方法做不到時，才建立新工具。

工程人員最後會看到什麼？

重點不是程式碼，而是「做了什麼、影響多少、是否成功、能不能復原」。

如何部署與開始使用

首次部署只做一次；完成後，BIM 工程人員每天只要開啟 Revit、啟動 Agent，再用自然語言下指令。

目前是 V0.5 測試版尚未提供一鍵安裝程式。首次部署需要具備 Windows、Revit 2024、Node.js 22+、.NET SDK 10 與 Codex Desktop，建議由 BIM 管理者或資訊人員處理。

首次部署：管理者執行

1
下載專案

從 GitHub 取得完整 repository，安裝 Node dependencies。

2
建置並安裝 Revit Add-in

建置會檢查 Gateway、C# 核心與工具清單，再安裝到 Revit 2024 Addins。

3
連接 Codex

設定 Codex 只使用 bim-personal-agent，連線埠固定為 localhost:9686。

4
安裝 BIM Agent skill

將 skills/bim-agent 放進 Codex 個人 skills 目錄，讓新 task 能用 $bim-agent 啟動。

顯示安裝指令
git clone https://github.com/NicheSam/BIM-personal-agent.git cd BIM-personal-agent npm.cmd --prefix gateway ci powershell -ExecutionPolicy Bypass -File scripts\install.ps1 python scripts\configure-codex-agent.py Copy-Item skills\bim-agent $HOME\.codex\skills\bim-agent -Recurse

每天使用：BIM 工程人員

1
開啟 Revit 2024 與工作模型

確認目前 active document 就是要操作的模型。

2
啟動 Agent 服務

在 Revit 的 BIM Personal 頁籤按「Agent服務 開/關」。

3
在新 Codex task 輸入 $bim-agent

Skill 會檢查 Revit 連線、讀取目前模型並開啟活動控制台。

4
直接描述工作

例如：「把目前視圖的風管依樓層分類，並回報數量。」

5
查看結果

在 Revit 檢查模型；在 Codex 與活動控制台查看執行內容。

Revit 已開啟且有 active model
Agent 服務已啟動localhost:9686
Codex 使用 $bim-agent即可開始自然語言操作

三個你需要知道的安全規則

正常建立與修改直接執行；只有高風險行為需要你在 Revit 再確認。

A

一般修改直接做

建立、移動、修改參數等可復原工作，不會每一步都跳確認視窗。

B

刪除前一定問

刪除、清除、覆寫等操作，先在 Revit 顯示實際影響範圍，再由你決定。

C

失敗就不留下半成品

同一批多步驟工作中途失敗時，整批退回，不保留只完成一半的模型狀態。
